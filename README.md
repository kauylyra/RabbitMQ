# RabbitMQ

Estudando RabbitMQ com .NET 10

Este projeto foi desenvolvido com o objetivo de estudar e entender melhor como funciona o RabbitMQ e a comunicação entre aplicações através de mensagens.

Utilizei o .NET 10 e criei duas aplicações de console dentro da mesma Solution: uma para enviar mensagens (Producer) e outra para receber e consumir essas mensagens (Consumer).

🚀 Tecnologias utilizadas
C#
.NET 10
RabbitMQ
Docker
📌 Como funciona?

O projeto está dividido em duas aplicações:

Producer: responsável por enviar mensagens para uma fila no RabbitMQ.
Consumer: responsável por receber e consumir as mensagens publicadas nessa fila.

A ideia é executar as duas aplicações e acompanhar o funcionamento em tempo real, observando quando uma mensagem é enviada pelo Producer e quando ela é recebida pelo Consumer.

Com isso, consigo entender melhor como funciona a comunicação assíncrona entre aplicações e como o RabbitMQ pode ser utilizado para facilitar essa comunicação.

🎯 Objetivo do projeto

Este é um projeto de estudos, criado para praticar e aprender mais sobre mensageria, filas e integração entre aplicações utilizando C# e .NET.

Pretendo continuar evoluindo o projeto conforme avanço nos estudos e aprendo novos conceitos.
